# Fuentes oficiales y precedencia

Auditoría documental: 2026-09-07. Se consultaron el índice SAT 2026, RMF base, Anexo 24, textos de CFF/LISR/LIVA/LIEPS, trámite DIOT y decreto de subsidio; esto no significa que todos los enlaces técnicos heredados ni todas las reformas estén verificados. Las reglas se aplican al periodo del hecho, con transitorios; no usar automáticamente la última versión para históricos.

## Precedencia práctica

1. Ley, Código y decreto publicado en DOF.
2. Resolución Miscelánea Fiscal y anexos vigentes al periodo.
3. Anexo 20, XSD, catálogos y matrices de validación publicados por el SAT.
4. Guías y documentación técnica oficial.
5. Material de terceros sólo como orientación; nunca como única base de una conclusión normativa.

Si dos documentos parecen contradecirse, registrar versión y fecha, citar ambos y escalar para revisión profesional. No resolverlo por intuición.

## Expediente de fuente y autoridad

Por conclusión registrar URL, título, autoridad, publicación, artículo/regla/página, vigencia inicial/final, transitorio, fecha de consulta y estado: texto consultado, sólo índice localizado o pendiente. Para esquemas/layouts conservar archivo y hash cuando se descarguen. No inventar hashes, fechas ni afirmar lectura completa porque apareció un resultado de búsqueda.

Si una página falla, buscar el mismo documento en SAT/DOF/SIDOF; usar copias de terceros sólo para localizar el original. Si no se recupera, marcar la conclusión específica pendiente y continuar con lo verificable. Las guías históricas no prueban obligación actual. Las versiones anticipadas requieren analizar la regla que les atribuye efectos y la publicación posterior; no equipararlas automáticamente al DOF ni descartarlas sin revisión.

Fuera de SAT: consultar IMSS/INFONAVIT para cuotas y sistemas, INEGI para UMA/INPC, Banxico/DOF para tipos de cambio según supuesto, STPS para trabajo/REPSE, ANAM y SAT para aduanas y autoridad estatal/municipal para impuestos locales. CINIF identifica NIF; el estándar financiero no se presume por el régimen fiscal. Son rutas de investigación, no materias certificadas por esta auditoría.

## Regla de actualización

Al responder sobre “hoy”, “vigente” o un ejercicio nuevo:

1. comprobar publicación oficial del ejercicio;
2. registrar URL, título, fecha y fragmento/regla aplicable;
3. comparar cambios de versión con la fecha del CFDI;
4. actualizar reglas como datos versionados, no como condicionales dispersos en código;
5. indicar si la conclusión es normativa, técnica o una inferencia de producto.
